# SDRmon

A terminal-first SDR monitoring and analysis toolkit for Python.

Connect an SDR.
Tune a frequency.
Watch the spectrum.
Scan bands.
Capture IQ.
Replay it later.

Everything from the terminal.

## Installation

```bash
pip install sdrmon
```

## Quick Start

```bash
sdrmon
```
